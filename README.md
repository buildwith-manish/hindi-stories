# Hindi Stories — Ankahi Ghar Ki

Short vertical story videos (1080x1920) made with [Remotion](https://www.remotion.dev/).
Each story is a small JSON file, rendered twice: once for YouTube Shorts, once for Instagram/Facebook Reels, each with its own end card.

See [`remotion/README.md`](remotion/README.md) for setup and how to make a video.

```
cd remotion
npm install
npm run studio
npm run render -- stories/001-papa-bus-pass.json
```
